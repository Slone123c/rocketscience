# Changelog

## 0.2.0 — 2026-11-13

- Added Windows (`x86_64` and `ARM64`) and Linux (`x86_64` and `ARM64`) desktop builds with system proxy management and tray panel (AppIndicator on Linux).
- Added the official website with light/dark theme support, UI screenshots, and interaction clips.
- Added a pulsing origin marker on the connection route trajectory map.
- Core features: live overview deck, proxy group latency testing and sorting, route trajectory map, step-by-step network check, subscription and local YAML profile editor, rule override groups with walkthrough, connections view, and automatic proxy restoration on stop or quit.

## 0.1.0

- Initial macOS release (`darwin/arm64`, `darwin/amd64`) with system proxy and TUN mode support.
